# Security Policy

## Supported versions

Security fixes are accepted for the latest `2.x` release line.

## Reporting a vulnerability

Please report security issues privately by email to **glebvoronkov03@gmail.com**.

Include:

- PLER version (`pler --version`)
- OS and build (CPU-only or CUDA)
- Steps to reproduce
- Impact assessment if known

Do not open a public GitHub issue for vulnerabilities until a fix is available.

There is currently no bug bounty program.
